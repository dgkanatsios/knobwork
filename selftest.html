Knobwork Self-test

Runs the protocol library against a connected amp: its reads, parameter and on/off changes, a model change, a block swap, tempo, tuner, settings, amp character, a temporary preset load and saves. It puts everything back and then checks every preset, amp bank and setting against a snapshot taken at the start.

The current preset must be a stored preset. Unsaved changes are kept only when they were loaded as a temporary preset (as the official app loads library and ToneCloud presets); otherwise save or discard them first. It takes a few minutes; keep this tab open.
